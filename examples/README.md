# Postcard example gallery

These examples use source photos supplied and authorized for this project. The six reviewed designs demonstrate one extracted subject, an outward watercolor wash, scene-matched typography, and lower-panel placement chosen independently from the source photo.

The image tool was the image-generation capability available in the current Codex session. Its underlying model identifier was not exposed, so this repository does not invent or claim a model name. These examples illustrate the visual direction; they do not establish consistent execution by every Agent or image model.

## Publication and rights

- Source and result images in this gallery are excluded from the repository's CC and MIT licenses and are provided only for project presentation unless a file states otherwise.
- Do not reuse, redistribute, train on, or commercially exploit a gallery image without separate permission from its rights holder.
- Do not submit a recognizable person's photo or result to a public gallery without the necessary consent.

## Adding another case

Keep each source/result pair adjacent, record the real platform or tool without guessing a model, verify the actual pixel ratio, state the place-evidence basis, and publish only a reviewed final—not an unreviewed draft.
