# Security and privacy

## Supported version

Security and privacy fixes target the latest release.

## Report an issue

Open a private GitHub security advisory for vulnerabilities involving arbitrary file access, path traversal, command injection, dependency confusion, or unintended network access. Use a normal Issue for non-sensitive bugs.

## Trust boundaries

- Installing a Skill grants an Agent instructions it may follow. Review `SKILL.md` and its referenced files before use.
- The bundled Python tools validate and package the repository; they do not assemble or modify the postcard artwork.
- Image uploads are governed by the chosen Agent or image provider, not by this repository.
- Never publish private photos or recognizable people without the necessary rights and consent.
