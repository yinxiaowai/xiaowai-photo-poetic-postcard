# 已编译提示词示例｜荔波小七孔

这是一份“分析完成后、真正送入生图模型”的示例。它用于展示字段应如何具体化，不得把本例的地点、主体、颜色或文案套用到其他照片。

```text
【画面结构】
根据上传的唯一一张荔波小七孔原图，生成一张完整的精确 3:4 竖版诗意明信片。整张画布严格水平分成上下两个独立区域，上下等高、各占 50%。绝对不允许整张图全部转绘：上半区必须保留原摄影，下半区才做艺术转绘。上方照片、下方转绘、纸张、标题、短注、三枚色卡和全部排版必须在同一次生图中一次性生成；禁止先生成局部后拼接，禁止事后用程序排字或贴色卡。所有文字和色卡 100% 限制在下半区，不能进入上半区。最终只交付一张完整成品，禁止主动生成四种风格、四张候选、四宫格、对比图或单独的下半图。

【上半区｜原摄影锁定】
上半区使用上传的荔波小七孔原摄影。画面主体是横跨碧绿色水面的古石桥，桥后为山林，右侧有近景古树，保留原图中桥体横向延展、桥洞倒映、古树与山林形成前后层次的空间关系。以 cover 方式铺满整个上半区，贴齐整张画布顶部、左边和右边，不留纸边、白边、描边、轮廓线、边框、相框或阴影。只允许为铺满上半区进行必要的等比裁切；不得拉伸，不得生成式扩图，并应完整保住古桥主体。完整保留原图的光影、色彩、空间关系和摄影质感，不得重画、替换、美化、修饰、增删或改写任何摄影内容。上半区除原摄影外绝对不能出现文字、色卡或其他元素。

【下半区｜单一主体转绘】
只提取并转绘覆有藤蔓的古石桥，不是把整幅原图、同一山水场景或完整背景再画一遍。仅保留三个最低必要辨识线索：连续石质桥身、三个可见拱洞、贴附桥面的藤蔓。明确省略并禁止出现：整片山林、右侧高大古树、远山、天空、完整河面和远景树木。采用“拆解 → 选择性保留 → 蒸馏 → 重构”，以透明水彩层染、轻水粉、少量彩铅表现石材纹理、藤蔓层次和青绿色关键配色。主体约占下半区宽度 62%，在下半区中部略偏上横向展开；保持完整自然轮廓，边缘自然消融进纸面，不触碰下半区左右边缘或下边缘。下半区至少保留 45% 连续、明显、干净的纸面，密度介于“孤立小图标”和“完整场景水彩”之间。桥洞下方只允许少量紧贴主体的浅水绿色晕染，不得形成完整水面、可识别背景、第二场景、矩形图块或第二主体。

【文字与三枚色卡】
标题严格写作“荔波小七孔”，短注严格写作“碧水古桥静立”，使用有设计感的现代宋体，两行横排，逐字准确，只出现一次。文字组仅放在下半区右下的干净留白处。另在下半区左下放置三枚从原图提取的色卡，颜色依次为深苔绿色 #2E4B1F、碧水青绿色 #3F8F76、嫩叶黄绿色 #98A91A。三枚色卡必须等大、极小、完美正方形、紧凑横排；每枚边长约为下半区总宽度的 1/20；内部 100% 均匀纯色平涂。禁止纹理、图案、渐变、圆形、异形、照片切片或第四枚色卡。文字组和色卡组不得遮挡桥体，不得进入上半区。

【禁止项与交付】
禁止下半区完整复刻荔波小七孔山水场景，禁止保留整片山林、右侧高大古树、远山、天空、完整河面和远景树木，禁止上半摄影被转绘，禁止上半区出现文字或色卡，禁止外框、照片边框、阴影、悬浮卡片、Logo、签名、水印、英文或任何未指定文字。检查实际像素比例、上下各 50% 分区、原摄影保真、单一古桥主体、具体省略项、留白、准确文字和三枚正方形色卡。任何一项失败都应在生图阶段修复同一张完整作品，不得改用拼接或程序排字。最终仅展示并交付一张通过检查的完整成品。
```
