# 照片诗意明信片｜独立绘图规范

请阅读本文件全文，观察用户上传的照片，制作一张由上方原摄影、下方主体艺术转绘、中文标题、短注和三枚取色色卡组成的完整明信片。

本文件可以单独使用：上传照片后，把这份 MD 作为附件交给能读图的生图 Agent，或复制全文到对话中即可。不需要安装 Skill、访问项目首页、读取其他文件或填写变量。没有额外要求时，请自行完成观察、取舍、文案和构图；用户提出调整时，按第十三节处理。

## 一、照片在作品中的两种用途

同一张上传照片承担两种不同的视觉任务：

- **上方摄影原片：** 呈现这次拍摄真实记录的主体、环境、光线和空间关系。这里的环境属于原片，应保持摄影面貌。
- **下方创作依据：** 从照片里选出一个值得记住的主体，提取必要辨识特征，用艺术媒介重新表现。这里的环境需要经过取舍，不能因为上方有树林、建筑或河面，就把它们全部带到下方。

上下两部分通过同一个主体及其色彩建立联系。联系来自内容，不要求把原片的全部景物、取景范围和构图再重复一遍。

只以用户上传的照片和用户明确提供的信息作为事实依据。本文件中的桥、人物、猫、船等只是说明取舍方法；照片没有的内容不得引入。

## 二、先观察，再决定画什么

生成前先完成以下判断，通常不需要向用户展示分析过程：

1. 找到第一眼最吸引注意的对象，观察其轮廓、大小、方向、姿态、光影和代表色。
2. 判断哪些细节使它可辨认，哪些只是在同一张照片里出现。
3. 选择一个明确主体，并形成两份简短清单：必须保留的特征、下方需要删除的环境。
4. 检查有无可靠地点信息，再确定文案。
5. 根据主体的形状与视觉重量，安排下方主体、文字和色卡的位置。

选择主体时，优先采用用户明确指定的对象；否则结合视觉焦点、独特性和照片主题决定。画面最大的区域不一定是主体：大片天空可能只是背景，小小一艘船反而是记忆中心。

若有多个同等重要对象，选择最能独立表达照片主题的一个；若它们的互动不可拆开，可视为一个紧凑主体单元，例如抱着玉米的小猫。不能借“组合主体”把整条街、整片山林或整幅风景重新带回来。

若没有显著物件，可选择一段独特山体、一株树或一组紧凑岩石作为自然主体。只有当选择会明显改变用户表达意图、且无法合理判断时，才询问希望突出哪个对象。

## 三、主体提取与信息取舍

下方按“观察拆解 → 选择主体 → 保留必要特征 → 去除环境 → 艺术转绘”的顺序处理。

### 保留什么

保留主体的整体轮廓、重要比例、主要结构、姿态和代表色。另选零至三个最有价值的辨识线索，例如桥洞、屋顶层次、救生衣或直接互动的物件。

“零至三个”限制的是额外辨识线索，不是把人物五官或建筑结构只剩三笔。主体仍应完整可辨，内部允许有适度材质和水彩细节。

判断某个伴随元素是否需要保留，可以用两个标准：

- 移除后是否会让主体难以识别，或破坏核心动作关系？
- 它能否紧贴主体、以很小的面积存在，而不形成另一个场景？

都不能满足时，删除它。

### 删除什么

建立针对本图的具体删除清单，直接点名对象，例如“右侧古树、远处山林和宽阔河面”，不要只写含糊的“简化背景”。

默认删除与主体无关的天空、远山、树林、街道、邻近建筑、围观人群、灯杆、杂物和大面积地面。它们只在被选为主体本身时才保留。

主体提取不是把原图缩小、降低透明度、模糊背景或换成水彩滤镜。下方如果还能清楚看出上方整幅照片的前景、中景、远景，就说明环境保留过多。

## 四、不同题材的具体处理

| 题材 | 优先保留 | 下方省略 | 可接受的轻微补充 |
| --- | --- | --- | --- |
| 古桥 | 桥身、拱洞关系、贴附的藤蔓或苔痕 | 成片山林、独立古树、远山、完整河景 | 桥洞附近一点水色或短小倒影 |
| 建筑、亭台、寺庙 | 主建筑轮廓、屋顶节奏、独特门窗或入口 | 相邻楼群、天空、广场、游客、远景 | 少量直接承托主体的基座 |
| 人物 | 可辨认的面部、发型、服装、关键姿态 | 拍摄地点的完整山水或街景 | 一个局部环境色晕染；必要的手持物 |
| 动物 | 面部、毛色、姿态和身体轮廓 | 庭院、墙面、大面积地板、杂物 | 直接触碰且体现动作关系的物件 |
| 船、车辆 | 船身或车身、独特结构、方向 | 城镇、山体、整片水面或道路 | 紧贴底部的一小段倒影或承托笔触 |
| 花环、花束、装置 | 完整外形、内部负空间、枝叶和主色 | 草坡、路灯、远景设施、天空 | 根部附近少量淡色或必要支架 |
| 自然风景 | 一个明确的自然形态或地貌焦点 | 与焦点竞争的其他山体、大片天空、零散景物 | 紧贴轮廓的浅淡环境色 |

这些方法用于指导观察，不要求所有建筑都相同细节、所有人物都相同大小。主体自身细节较多时，可以在主体内部表现丰富层次；不要靠添回环境增加丰富度。

## 五、整张画布与上下关系【画面结构】

默认采用精确 3:4 竖版，水平分成上下两个等高、独立的区域，各占 50%。上半是摄影，下半是纸面艺术设计。没有用户额外要求时，保持这个明确分区。

例如 1080×1440 的完整画布，上下区域各为 1080×720；这说明上下各半是分区高度，不是要求下方插画占满 720 像素。

上下直接相接，分界清楚。纸张颜色和取色使作品协调，但不能用大范围渐隐把摄影区与插画区混成一张全幅水彩。

整张作品必须在生图环节一次生成，包括摄影呈现、转绘、纸张、所有文字、色卡和排版。不能先画下方再拼到原片上，也不能生成后用程序贴字、色块或边框。

## 六、上方摄影的适配【上半区｜原摄影锁定】

照片铺满整个上半区，贴齐画布顶部、左边和右边，无纸边、白边、描边、相框、圆角或阴影。

上方“无留白”和下方“有留白”是两个独立规则，不可混用。默认整图宽 W、高 H：从画布左端到右端、顶部到 H/2 分界线，整个矩形都由摄影内容覆盖；照片底边直接抵达分界线，也不垫纸条或分隔描线。上半区不是纸面上缩小摆放的一张照片。纸张肌理和文艺留白只属于下半区，不能围绕整张作品形成米白外框。

检查上方三个外缘和分区交界：只要照片与画布顶部、左侧、右侧之间出现纸边，或照片四周出现细线，就判定未通过，即使下方转绘正确也不能视为合格。

保持原摄影的主体、光照、色彩关系、空间关系和真实质感。下方选择艺术媒介不会改变上方的摄影表现。上方不增加标题、短注、色卡或装饰。

原片与照片区比例不一致时：

- 等比放大到能覆盖该区域，再移动取景框，让关键主体处于合适位置。
- 横向建筑优先保住屋顶和两侧关键轮廓；人物优先保住脸部、必要手势和重要服装信息。
- 不得横向拉宽人物、压扁建筑或生成不存在的两侧风景。
- 如果既定分区无法容纳必要主体，就说明裁切冲突，并给出调整照片占比或画布比例的具体选择；不能擅自拉伸、扩图或塞入巨大左右留白。

“保留原片”要求可见内容忠实，不意味着在任意比例下都能同时保留原文件的全部边缘。只做必要裁切；无法兼顾时明确说明。

## 七、艺术表现与细节密度【下半区｜单一主体转绘】

只提取并转绘已选定的一个主体。默认采用清透水彩，辅以少量轻水粉和必要的彩铅线条，保留可辨轮廓、结构层次及主要色彩。

- 水彩以透明叠色、自然渗边和轻微干湿变化表现，不给整个照片统一套滤镜。
- 水粉只用于主体局部较实的体积或亮部，避免把插画画成沉重的大色块。
- 彩铅只帮助交代关键结构，不逐一描摹每块砖、每片叶和所有枝条。
- 细节集中在识别最需要的区域，边缘和次要部位可以逐渐简化、融入纸面。
- 已被原图裁断的主体，可保留自然局部构图并淡出，不能为了补齐轮廓虚构未见结构或肢体。

画面丰富度应来自主体内部的层次、材质、光影和笔触。若太单薄，先补一点主体细节或贴近主体的轻微承托；若太满，先删环境，再收小主体和晕染。

用户选择水墨、版画、彩铅或其他媒介时，改变下方笔触和材料表现，同时保持主体取舍与分区关系。

## 八、尺度、位置与留白

所有尺度均以下半区本身为参照。以下是构图起点，需同时看宽度、高度和视觉重量：

- 桥梁、横向建筑等通常使用下半区宽度约 55%—70%，保持较低的高度，避免桥和水色占满整个面板。
- 人物、动物和紧凑物件通常使用宽度约 40%—55%；纵向主体不能为凑宽度而挤到上下边缘。
- 简单圆环、符号或内部空洞较大的装置，通常从较小尺度开始；关注外轮廓的视觉重量，不能只因中间是空的就放得很大。
- 复杂建筑可以保留更多内部细节，但仍要给轮廓外侧、标题和色卡留出空间。

默认至少约 45% 下半区保持可见的安静纸面。这里的留白是连续、低对比、没有景物占据的区域；铺满浓重水彩后调浅颜色，不算干净留白。比例是观察目标，不要求 Agent 声称做过精确像素分割。

主体可以偏左、居中或偏右，也可以略高或略低。主体轮廓与下半区四边保持安全距离，建议从宽度的约 5% 起观察调整。留白应能容纳清楚文案，同时保留一块不放任何元素的休息区域。

## 九、纸张、晕染与色彩

默认下半区使用温暖、低饱和的浅米白纸底，纤维纹理细而弱，不得变成浓重噪点、污渍或大块斑驳。上方原片不覆盖纸纹滤镜。

配色从原图实际存在的颜色中选取：主体主色负责辨识，较深颜色用于结构和文字，较浅颜色用于轻微承托。可以适度降低饱和度，不强制每张照片都变成同一种绿色或橙色。

主体后方最多使用一个局部、柔和、半透明、不规则的环境色晕染，也可以完全不使用：

- 晕染沿主体附近展开，边缘自然退入纸面。
- 不形成矩形照片底板、完整圆盘或大面积不透明几何块。
- 不在晕染里重新画树林、云层、远山、建筑或第二个焦点。
- 当晕染开始占据文案区域，或模糊主体边界，应缩小或减淡。

## 十、地点识别与文案创作

先确定事实，再写文字。地点证据按以下顺序判断：

1. 用户明确提供的地点或景点名称。
2. 照片中清楚可读的名称，或实际可读取的 EXIF、地理信息。
3. 具有唯一辨识特征、能够高置信度确认的公开地标。

不得假设所有上传图片都有定位数据，也不得根据一座相似的桥或山形断言地点。需要外部核实且有搜索能力时可以核实；没有可靠依据时不猜。

确认地点后，其准确名称必须在标题或短注中至少完整出现一次。较长地名可以留给短注，不为了凑字数删掉关键名称。牌匾只能证明牌匾所写的名称，不能据此臆造所属城市或景区。

没有确认地点时，标题围绕可见主体、动作、光线或情绪创作。标题通常 3—6 个中文字符，短注通常 6—10 个中文字符；自然、准确比机械凑字数更重要。短注补充标题没有表达的画面感，避免重复标题或加入照片不能证明的故事。

用户给出的文字逐字保留。英文版规范默认也生成中文文案；只有用户要求其他语言时才切换。没有指定内容时自行拟定，不要求用户填标题模板。

## 十一、字体与文案位置

默认使用清楚、克制的现代宋体感，标题较大，短注较轻，形成一个紧凑的文字组。建筑可用稳重笔形，自然题材可用更轻的人文衬线；只有用户要求或清晰度允许时采用手写风格。

文字颜色从原图选取较深、易读的一色，和纸面形成足够对比。不要默认用最鲜艳的强调色抢主体。

根据插画轮廓选择文字位置：

- 主体偏右时，优先观察左侧连续空位。
- 主体偏左时，优先观察右侧空位。
- 横向主体位于中上部时，可以把文字置于下方左侧、右侧或中间。
- 纵向主体占据中部时，可以考虑侧上方或侧下方，避免挤成最底部一条。
- 居中布局本身合理时可以居中，不必为了变化强行偏移。

文字仅在下半区，不能进入摄影区、穿过主体或贴住画布边缘。文案太长时优先调整断行、字号和附近空间，不能压扁字体或挤大下半区来解决。

## 十二、三枚色卡的形状与自适应位置【文字与三枚色卡】

默认从原图选择三种有代表性且能区分的颜色，组成一个小组。可选主体主色、环境辅助色和结构深色；避免挑选三种几乎相同的颜色。黑白照片可以使用可区分的三个灰阶。

色卡只承担取色提示，不是第四个视觉主角：

- 恰好三枚等大的完美正方形，紧凑横排。
- 每枚边长约为下半区宽度的 1/20，存在感应轻。
- 内部 100% 均匀纯色平涂，不加纸纹、图案、渐变、图像切片、文字标签或投影。
- 色卡从原片取色，不画成有照片细节的“缩略图”。
- 不使用圆形、异形或第四枚色卡。

将色卡组放在下半区的左上、右上、左下、右下任一有足够空间的角落，并与边缘保持距离。这里的左上/右上指下半区顶部附近，绝不指整张作品上方的摄影角落。

先观察主体和文字占据的位置，再从余下角落选择。多个位置都成立时可随机择一；遇到遮挡或失衡时重新选择，不为随机性牺牲构图。连续制作不同照片时，应让主体、文字和色卡形成自然变化。

## 十三、用户可以自由调整的部分

本文件提供默认设计方法。用户的明确设置优先于默认值，自动判断负责补齐未指定项：

| 可调整项 | 处理方式 | 同时保留的原则 |
| --- | --- | --- |
| 图片比例或像素尺寸 | 按用户指定的横竖比例或尺寸重新安排画布 | 一个完整作品，比例不靠拉伸伪造 |
| 上下占比 | 指定后重新计算两区高度 | 上方仍是摄影，下方仍是主体转绘 |
| 转绘风格 | 改变下方媒介、笔触和细节密度 | 提取同一主体，保留身份与结构 |
| 主体大小、偏移 | 可更小、更松弛，或适度加大 | 留出轮廓外空间，不靠添回背景填满 |
| 纸底和色调 | 暖白、冷白、平滑纸或细纤维；冷暖和饱和度可微调 | 不对上方原片套同样的艺术滤镜 |
| 标题、短注、语言、字体 | 采用指定文字，可省略短注或全部文字 | 显示时准确可读；仅在下半区 |
| 色卡 | 可以改位置、从原图另取颜色、缩小或隐藏 | 显示时仍为三枚等大纯色正方形 |
| 下方布局 | 按主体形状重新安排插画、文字与色卡 | 各组清楚、不互相遮挡 |

当用户选择“不要文字”或“不要色卡”时，相应默认要求和检查项不再适用，腾出的空间可以保持空白；不能为了填满而补回整景。明确要求其他语言时，也不再执行“仅中文”的默认限制。

## 十四、如何在不同 Agent 中执行

只要当前环境能够读取照片并根据参考图生成作品，就可以直接按本文件完成任务。用户无需安装项目、运行代码或指定某个唯一模型。

如果你作为 Agent 需要调用独立生图工具，请把观察结果写成完整、具体的绘图指令，保留本文件适用于该照片的要求，并随调用附上原图。不得概括到丢失主体、删除清单、分区、文案、色卡和留白；可以把通用解释转成这张照片的明确决定，不必把工具能力说明画进图中。

传递给生图模型的指令应分别交代【画面结构】【上半区｜原摄影锁定】【下半区｜单一主体转绘】【文字与三枚色卡】【禁止项与交付】。每部分都需包含已作出的具体决定，不能只传标题或要求生图模型另读其他文件。

- **能看图、能生图：** 自行分析并生成，正常交付成品，不强制先让用户审阅提示词。
- **能看图、不能生图：** 输出针对该照片的完整绘图指令，说明还需要在支持参考图的生图工具中使用。不要把本通用规范原封不动当作已分析结果。
- **不能看图：** 说明无法判断源图内容，不能臆造主体与地点。需要换到能读图的环境，或由用户补充画面描述；描述不能替代原摄影保真的参考图输入。
- **输入长度受限：** 不静默截断规定。先具体化与本图相关的决定，保留全部生效约束；仍超限时说明限制并提供完整指令供其他入口使用。

如果有真实可用的尺寸、比例和张数参数，需与文本指令一致。参数无法设置时明确所能做到的范围，不虚报已经设置成功。

## 十五、完成前检查与针对性修正【禁止项与交付】

先看构图是否成立，再看局部细节：

1. 实际比例符合要求；默认是 3:4，而不是看起来相近的 2:3。能读取像素尺寸时据实检查，不能读取时不要声称已精确核验。
2. 上下区域边界和占比明确；默认各 50%，上方摄影满幅无纸边。
3. 下方只出现选出的主体及必要贴附线索，具体删除清单中的背景没有回来。
4. 主体大小适中，周围有连续干净纸面；不是缩小后的第二张完整风景画。
5. 已确认的地点名称没有遗漏，未确认地点时没有编造名称。
6. 文字逐字正确、字号可读，并且全部处于下半区。
7. 色卡数量、形状、大小、纯色和位置正确；用户选择隐藏时确认没有残留。
8. 没有额外装饰、说明字、Logo、签名、水印、边框或候选拼图。

发现问题时针对成因修正：整景复刻就删除被带回的环境；太满就缩小主体和晕染；太空就补主体自身细节；文字挤压就重新安排文字空位；色卡像碎片就明确纯色填充并重试。

修正仍需在生图阶段生成完整作品，不能改用程序拼接、裁切成品或补字。若工具持续无法满足要求，说明具体未达标项，不把失败结果称为合格，也不无限重复生图。

## 十六、最终交付

默认一张原图交付一张完整明信片。摄影、主体转绘、纸面、文案、色卡和布局属于同一张生成作品。

不主动生成多风格候选或四宫格。若平台自动返回多张、且 Agent 能选择呈现，只展示一张符合要求的结果；不能控制平台自动预览时据实说明。

正常完成时展示成品即可，不附内部分析、候选标题、参数说明或本文件章节文字。用户要求解释时再提供简要设计说明。
