# 照片诗意明信片｜可直接使用的中文提示词

当你的 Agent 无法安装 Skill 时，上传一张原图，再把本文件内容粘贴给具备图片理解与生图能力的 Agent。默认只输出一张最终图。

## 使用前可选填写

不填写就使用括号中的默认值：

- 画布比例或尺寸：`[3:4 竖版，1080×1440]`
- 上下区域占比：`[严格各 50%；仅在明确指定时调整]`
- 转绘风格：`[透明水彩 + 轻水粉 + 少量彩铅]`
- 纸张：`[温润、低饱和的浅米白纤维纸]`
- 地点信息：`[如已知请填写；用户明确提供的地名优先]`
- 标题：`[地点已确认时须在标题或短注中原样出现；否则根据画面拟定且不猜地名]`
- 短注：`[6—10 个自然中文字符]`
- 文字：`[现代宋体感，标题清楚，短注轻一些]`
- 下方主体尺度：`[中等偏小，至少保留约 45% 明显空白]`
- 版式：`[根据下半区真实负空间自适应，不固定左下文字、右下色卡]`
- 色卡：`[三枚，从原图取色，在下半区四角中择空位成组放置；每枚边长约为下半区宽度 1/20]`
- 其他要求：`[无]`

## 直接粘贴给 Agent 的完整指令

```text
请先查看我上传的唯一一张原图，再完成下面的任务。原图是唯一的事实与视觉来源。本代码块整体就是最终生图执行指令：如果你需要调用另一个生图模型，必须把下面所有分区和规则完整传入，不得概括、缩写、转述成一段普通风格描述，也不得把“只提取主体”改写成“把同一场景重绘”。

【能力判断】
如果你能够看图并直接生成或编辑图片，请先完成主体、删除清单、配色、标题和版式判断，再把本完整指令送入图片模型，在一次完整生图操作中生成并交付一张成品图。不得另写精简提示词。如果你能看图但没有生图能力，请先分析原图，然后输出一条保留本文件全部分区、并已经填好主体、删除清单、配色、标题、短注和参数的完整生图提示词；明确说明你没有实际生成图片。如果你无法查看原图，请直接说明缺少图片理解能力，不要猜测画面中的主体、颜色、地点或构图。

【画面结构】
把原图制作成一张完整的 3:4 竖版诗意明信片。整张 3:4 画布严格水平分成上下两个等高、独立的区域，各占 50%；只有我明确指定其他比例时才允许改变。绝对不允许整张图全部转绘：上半区必须保留原摄影，下半区才做水彩转绘。必须在同一次生图中完成上方照片区、下方转绘、纸张、标题、短注、三枚色卡和全部排版，不能先生成局部再拼接，也不能事后用程序贴文字或色卡。所有文字和色卡 100% 限制在下半区。最终只输出一张图，不主动生成不同风格、四张候选、四宫格、对比图或单独的下半图。

【先分析并固定】
采用“拆解 → 选择性保留 → 蒸馏 → 重构”。只选择原图中最值得提取的一个具体主元素，不能把“整幅风景”“同一场景”或“整张照片”当作主元素；最多保留零至三个属于主体本身、与主体直接相连或直接互动的最低必要辨识线索；同时用本图中的具体可见对象建立删除清单。删除背景杂讯、远景、天空、树林、山体、街道、人群和低信息装饰，不能为了画面丰富而保留可识别的完整环境。调用生图模型前，最终指令里必须明确写出“只提取并转绘［具体主体］”和“明确省略［本图具体删除清单］”，不能只写泛化词。从原图提取三种彼此可辨的代表色；拟定一个自然的中文标题和 6—10 个中文字符的短注。先建立地点证据卡，按以下顺序判断：我明确提供的地点或景点名称 > 原图中清晰可读的招牌、EXIF 或地理定位 > 只有在高置信度下才采用可唯一识别的地标。只要地点或景点已经确认，它的准确名称必须在标题或短注中至少原样出现一次，不能被泛化的诗意文案替代。证据不足时才使用基于画面的文案，并禁止硬猜地点、景点或建筑名称。

【上半区｜原摄影锁定】
让原图以 cover 方式完全铺满上半区域，照片必须贴齐整张画布的顶部、左边和右边，不留任何纸边、白边、描边、轮廓线、边框或相框，也不能把照片缩成悬浮小卡片。原图与照片区比例不同时，只允许为铺满区域做必要裁切；必须保住主角，不得拉伸或生成式扩图。完整保留原摄影作品的主体、光影、色彩关系、空间关系和摄影质感；不得重画、替换、美化、修饰、增加或改变照片内容。

【下半区｜单一主体转绘】
只提取并转绘刚才确定的一个具体主元素，不是把整幅原图、同一场景或完整背景再次画一遍。保留它最有辨识度的轮廓、结构、材质与关键配色；只允许零至三个与主体直接相连或直接互动的必要线索。桥只保留桥体和极少量贴近桥洞的水色，不保留整片森林、树木、山体或河景；船只保留船体和紧贴船底的倒影，不保留城镇、群山和完整水岸；人物只保留人物及其关键服装姿态，不保留可识别的完整风景。默认使用透明水彩层染、轻水粉和少量彩铅，颜色清透、有层次、有纸感。主体必须保留完整自然轮廓，边缘渐隐融入纸面；不能形成矩形图片块，不能加描边、边框、阴影或悬浮卡片。主体可根据轮廓偏左、居中或偏右。默认主体约占下半区宽度 55%—65%；横向或复杂主体可在约 55%—70% 内调整，人物、动物、圆环等紧凑主体通常占约 40%—55%。至少保留约 45% 明显、连续的干净纸面，整体密度应介于“孤立小图标”和“完整场景水彩”之间。主体后方最多只放一个局部、柔和、不规则、半透明的水彩晕染，不能扩展成背景场景或第二主体。

【文字与三枚色卡】
默认使用现代宋体感，两行横排：一行简洁中文标题，一行较轻的 6—10 字中文短注。文字必须逐字正确。先完成主体布局，再根据真实负空间，把文字组放在下半区的左上、右上、左下、右下或侧边空位之一。只在下半区放三枚从原图取色的、等大、极小巧、纯色、完美正方形色卡，并始终作为一个紧凑横排小组；每枚边长约为下半区总宽度的 1/20，内部 100% 均匀纯色平涂。色卡组同样从下半区四角中选择空位，尽量与文字组分处不同角落。不得永远固定为左下文字、右下色卡；连续制作多个案例时应主动变化合格版式。文字和色卡不能遮挡主体。色卡不得进入上半区，不得变成照片碎片、纹理块、图案块、渐变块、圆形、异形或第四枚色块。

【整体气质】
统一使用温润、低饱和的浅米白纤维纸底。整体清透、安静、诗意、雅致，有当代编辑设计感和中文艺术明信片气质。整张画布无外框；除指定标题和短注外，不出现英文、数字、Logo、签名、水印或任何额外文字。

【允许我二次调整】
如果我另外指定了画布比例或尺寸、上下区域占比、转绘风格、主体尺度或位置、纸张、标题、短注、语言、字体、色卡位置、配色倾向或是否去掉文字/色卡，请优先采用我的设置；但仍需坚持：原图是唯一来源、上方照片不做语义改动、下方只转绘一个主元素、最终只交付一张完整图。

【禁止项与交付】
生成前先检查送入图片模型的提示词是否仍完整包含【画面结构】【上半区｜原摄影锁定】【下半区｜单一主体转绘】【文字与三枚色卡】【禁止项与交付】，并且已经写明一个具体主体、具体删除清单、准确标题短注、三个具体颜色、文字位置、色卡位置、三枚完美正方形、边长 1/20 和最终只交付一张；缺少任何一项都不得开始生成。生成后检查实际像素尺寸，默认宽高比必须精确等于 3:4，2:3 不合格；默认上下严格各 50%；上方照片没有被重画或替换；下方只有一个主体和最低必要线索，不是整景复刻；删除清单中的对象没有进入下半区；至少约 45% 下方纸面保持明显空白；主体、文字和色卡根据负空间自适应分布；已确认地点的准确名称至少在标题或短注中原样出现一次，未确认地点时没有编造地名；文字准确；色卡数量、大小和形状正确；没有额外文字、Logo、水印、边框、阴影或多图候选。若第一次失败，只能在生图阶段修复同一张完整作品，不能用程序裁切、拼接或排字，最终只展示一张合格成品。
```

## 直接用于普通生图工具

如果工具只能接收图片与提示词，上传原图后复制上面代码块。若工具不理解“先分析”，先让一个能看图的 Agent 提取主元素、三种颜色、标题和短注，再把这些具体内容补入提示词。
